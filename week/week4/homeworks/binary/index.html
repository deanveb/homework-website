# Nhị Phân --- ## Nhiệm Vụ --- Tạo ra 1 chương trình nhận 1 tệp .txt qua command-line argument và in ra mã nhị phân trong hệ 16 của tệp đó **Điều Kiện**: - Nếu người dùng nhập sai cách dùng thoát chương trình với exit code 1 (Usage:...) - Nếu file không tồn tại thoát chương trình với exit code 2 **Nhắc Lại**: - Mỗi string đều kết thúc với nul - Phải giải phóng hết vùng nhớ (dùng valgrind để kiểm tra) ## Để bắt đầu --- Đánh vào terminal như sau:\ `$ mkdir binary`\ `$ cd binary`\ `$ code binary.c` #### Nhắc Lại **`mkdir`** ( hay make directory ) được sử dụng để tạo thư mục\ **`cd`** ( hay change directory ) được sử dụng để chuyển thư mục hiện tại sang thư mục khác ## Để chạy thử chương trình --- ` $ make binary `\ ` $ ./binary ` ## Nhắc Lại **`make`** là một trong những công cụ được sử dụng để chuyển (hay biên dịch) mã c sang mã nhị phân\ Có thể sử dụng **`ls`** để xem trong thư mục hiện tại có file/folder gì ## Để kiểm tra tính chính xác --- `$ check50 deanveb/HomeWork/main/week4/binary`
